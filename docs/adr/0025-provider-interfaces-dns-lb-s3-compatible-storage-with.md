# ADR 0025: Provider interfaces (DNS, LB, S3-compatible storage) with Cloudflare as the first implementation, not the only one

## Context

Otherwise the community reads it as vendor lock-in.

## Decision

Provider interfaces (DNS, LB, S3-compatible storage) with Cloudflare as the first implementation, not the only one.

Backups target any S3-compatible store (R2, B2, MinIO).

## Consequences

- This decision is binding for all contributors and agents. Changing it requires a new ADR approved by the maintainer (see ADR 0036).
