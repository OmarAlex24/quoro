## Context

The maintainer's answer to 'own use or product?': anyone can install it on a box they have and experiment; monetize later.

## Decision

Start as a self-use / experimenter tool; enterprise or managed offering later.

Target users: indie devs and advanced homelabbers; small startups wanting Railway/Vercel experience on own hardware/VPS; teams already operating with agents.
