## Context

Keep the project from losing its direction.

## Decision

Anti-drift rules.

Accepted ADRs are law; changing one requires a new ADR approved by the maintainer. Contracts freeze after M0; contract changes are standalone PRs reviewed on their own. Each workstream owns its paths. GitHub Issues + Milestones are the task source of truth (each PR closes an issue). Progress is reported in a fixed format (done / next / blocked / decisions needed). Each milestone ends with a demo on the test lab and the maintainer's approval before the next starts. Done = runs on the lab, not 'it compiles'.

## Consequences

- This decision is binding for all contributors and agents. Changing it requires a new ADR approved by the maintainer (see ADR 0036).
