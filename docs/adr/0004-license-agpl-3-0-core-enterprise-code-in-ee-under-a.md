## Context

Future managed/enterprise plans: AGPL prevents clouds reselling Quoro as a service without sharing changes; CLA keeps the option to sell commercial licenses of the core.

## Decision

License: AGPL-3.0 core, enterprise code in ee/ under a separate license, CLA from the first external contributor.

Model similar to GitLab / Cal.com open-core layout.

## Consequences

- This decision is binding for all contributors and agents. Changing it requires a new ADR approved by the maintainer (see ADR 0036).
