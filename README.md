# Quoro

One tool for virtual machines and application deploys on your own hardware. Quoro runs one microVM per app on Cloud Hypervisor + KVM, and gives you deploy, domains, TLS and logs in the same interface. It is built to be operated safely by AI agents: scoped, time-limited grants and an append-only audit log.

Status: design stage — nothing to run yet.
